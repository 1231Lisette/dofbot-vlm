# 课程要求摘要

来源文件归档在 `docs/course/`。本摘要用于开发时快速核对，原 PPT 为最终依据。

## 核心任务

课程主线是在 Dofbot 环境中完成包含数据传输和图像识别的分拣、堆垛系统。完整闭环
包括：摄像头采集、客户端识别、目标坐标、服务端解析、机械臂动作和完成反馈。

## 客户端与上位机

课程 PPT 要求上位机至少显示或提供：

- 摄像头视频流。
- 模型检测输出。
- 机械臂对应动作和当前运动/静止状态。
- 发送任务、结束运动等基本交互。
- 符合实际操作、功能直观且排版简洁的界面。

## Qt 与 Web 的结论

《综合设计IV-2026秋》第 11 页和评分标准第 7 页明确列出：

```text
界面开发环境：QT，C#，Web
```

同页说明 Qt 只是安装与使用样例，熟悉 C#、Web 等环境的同学可以使用自己的开发环境。
主课程第 33 页与评分标准第 11 页使用 Qt 举例描述上位机功能。因此本项目保留 Web
控制台，重点逐项覆盖界面功能，不为形式重写 Qt。

如果任课教师之后口头要求必须提交 Qt，可增加一个 PyQt `QWebEngineView` 桌面壳加载
现有 FastAPI 页面；后端、WebSocket、机械臂接口和业务逻辑无需重写。

## 必做功能

- Dofbot 真机控制。
- 摄像头视频采集与传输。
- 目标检测与目标坐标获取。
- 客户端与服务端通信。
- 抓取、分类放置和简单堆垛。
- 上位机界面和任务状态。
- 三个手势触发三个明确动作。
- 机器学习实验结果与数据分析。

## 本项目拓展功能

- MuJoCo 数字仿真和碰撞检查。
- 自然语言任务输入与结构化确认。
- 平面抓取候选生成、评分和路径净空。
- 视觉闭环验证、重试和失败统计。
- Web 实时三维模型与任务历史。

拓展功能不能替代真机抓取、视觉识别、通信、分拣和堆垛这些验收主线。

## 机器学习实验材料

最终汇报至少准备：

- 数据集类别、数量和训练/验证划分。
- 标注流程和典型样本。
- Precision、Recall、mAP@0.5 和 mAP@0.5:0.95。
- Loss 曲线和混淆矩阵。
- 真实桌面识别帧率与时延。
- 抓取、分拣、堆垛成功率及失败分类。
- 光照、遮挡和位置变化下的对比实验。
