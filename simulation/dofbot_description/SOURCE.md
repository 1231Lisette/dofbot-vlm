# Dofbot mesh source

The URDF and STL files in this directory were retrieved from the public
[`EliteGuzhva/dofbot`](https://github.com/EliteGuzhva/dofbot) repository at commit
`e50efb22639cca125df6bab01ce1f04d57188aee` on 2026-09-22. That repository describes
the files as a model of the Yahboom DOFBOT arm.

Yahboom's official Jetson repository confirms that the DOFBOT course includes ROS and
MoveIt materials, while its complete annex is distributed separately through the link
in `Annex_Download_Link.txt`.

The source repository does not declare a license. Keep this provenance note with the
assets. For redistribution outside coursework, replace these files with the official
URDF/STL package supplied with the course or obtain permission from the model author.

To replace the model, keep the filenames `base_link.STL` and `link1.STL` through
`link5.STL`, or update the `<mesh>` entries in `simulation/scene.xml`.

`link5_base.STL`, `link5_left_finger.STL`, and `link5_right_finger.STL` are
deterministic derivatives of `link5.STL`, generated by
`scripts/split_gripper_mesh.py`. They allow MuJoCo and Three.js to animate the two
original finger meshes instead of drawing unrelated placeholder jaws.
